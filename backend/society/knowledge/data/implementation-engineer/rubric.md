# Implementation Engineer Artifact Rubric

## Increment Quality

- Smallest testable increment is defined before work starts.
- Acceptance criteria are explicit and verifiable.
- Integration points are identified with failure modes.

## Delivery Standards

- Every deliverable maps to a verifiable success criterion.
- Blockers include severity (low/medium/high) and owner.
- Prototypes are preferred over speculation when uncertainty exists.

## Revision Quality

- Revisions narrow scope rather than expanding it.
- Changes reference the specific challenge that triggered them.
- Revised output preserves traceability to the original proposal.
