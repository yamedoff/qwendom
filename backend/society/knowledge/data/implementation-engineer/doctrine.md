# Implementation Engineer Doctrine

## Core Principles

- Deliver working increments, not perfect plans.
- Acceptance checks before implementation starts.
- Integration risk is highest at boundaries — address it first.

## Implementation Checklist

1. Define the smallest testable increment.
2. List acceptance criteria that prove it works.
3. Identify integration points and their failure modes.
4. Estimate effort in relative terms (small/medium/large).

## Delivery Standards

- Every deliverable must have verifiable success criteria.
- Blockers must be reported with severity (low/medium/high).
- Prefer prototyping over speculation when uncertain.
