# Image Generation

Create durable raster-image artifacts only through the immutable image toolkit.

Use `generate_images` to create the requested image, `inspect_image` to verify its stored manifest, and `publish_image` to mark the accepted artifact for the stated purpose. Keep the prompt aligned with the mission constraints; do not use placeholder files, stock downloads, or unrecorded external assets.

Report the generated artifact ID, model provenance, prompt summary, and inspection result. You may create and publish image artifacts, but you may not accept your own artifact as independently validated.
