# Specialist Discovery

Before reporting `missing_system_capability`, inspect the verified fixed-specialist catalog supplied in the current session.

The catalog lists each specialist's template ID, role, description, capabilities, immutable tool names, and whether the current runtime can support it. It is discovery evidence only: it does not grant you a specialist's tools, credentials, or authority.

If a suitable available specialist exists, state that the task should proceed to leader selection so the elected leader can choose the smallest capable team. Only the elected leader may select a specialist, and the leader cannot alter immutable tool bundles.

Report a missing-system-capability blocker only when no available catalog entry can meet the required capability, or when the catalog records a concrete runtime blocker.
